왜 만들었나

가족과 팀의 일정은 원래 여러 곳에 흩어져 있습니다. 각자의 캘린더를 따로 확인하다 보면 겹치는 일정을 놓치기 쉽습니다. Multi-calendar는 여러 캘린더를 한 화면에 모으고, 놓치지 않도록 알림까지 자동화합니다.

핵심 기능

배포 준비 단계까지 구현된 기능입니다.

멀티 캘린더 통합 뷰

가족·업무·개인 캘린더를 하나의 월간 뷰에서 색으로 구분해 확인합니다.

FCM 푸시 알림

Firebase Cloud Messaging으로 기기 토큰을 관리하고 일정 알림을 보냅니다.

일정 등록 · 수정 · 삭제

타임존 처리를 포함한 일정 CRUD를 지원합니다.

가계부(Ledger)

일정과 함께 지출 내역을 기록하고 관리합니다.

PWA + 모바일 빌드

PWA로 설치 가능하며, Capacitor로 모바일 앱 빌드까지 지원합니다.

Vercel Cron 스케줄

정해진 시각에 실행되는 서버 작업을 Vercel Cron으로 처리합니다.

아키텍처

요청과 알림이 흐르는 경로입니다.

Next.js 15 클라이언트
PWA로 설치되는 웹 화면. Capacitor로 모바일 앱으로도 빌드됩니다.
→
Firebase Auth · Realtime DB
로그인과 캘린더·일정·가계부 데이터를 저장합니다.
→
