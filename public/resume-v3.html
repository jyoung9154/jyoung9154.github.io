장시간 파이프라인 실패의 DLT 보존과 지연 재접수

안정성 · 2026.07

배경분석 1건이 수십 초 소요. 1·2·4초 즉시 재시도는 동일 원인으로 재실패해 비용만 증가

수행파이프라인 실패를 즉시 DLT로 이동, 스케줄러가 60분 경과 메시지의 retryCount를 증가시켜 원 토픽에 재발행 후 offset 동기 커밋

성과실패 유실 없이 지연 재처리. retryCount 증가를 테스트로 확인

한계재발행 후 커밋 전 장애 시 중복 발생 가능. at-least-once이며 exactly-once로 표기하지 않음

인증·SSO·테넌트 경계

보안 · 2026.07 ~ 09

배경API가 permit-all 상태. 대시보드에서 Axios 요청과 SSE가 동시 401을 받아 회전형 refresh token을 이중 소비해 한쪽이 무효화되는 경쟁 조건

수행JWT 필터 도입과 ADMIN·OPERATOR·VIEWER 경로 규칙 수립. 토큰 갱신을 공유 Promise single-flight로 통합. A10 SSO는 Redis 10분 TTL nonce와 cookie state 상수 시간 비교 후 1회 소비, 사용자 키를 `(group_seq, login_id)` 복합 unique로 전환

성과무토큰 401, VIEWER의 ADMIN 경로 403, OPERATOR 실행 200을 테스트로 고정

한계운영 SSO 로그인 성공·키 관리·침투 테스트는 본 커밋 범위 밖
