CORE FEATURES

핵심 기능

▲5전략 병렬 매매

모멘텀·역발상·신호·변동성·DCA, 성격이 다른 5개 전략이 동시에 독립 운용된다.

◈수익률 악화 자동 감지 → 재튜닝

성과가 나빠지는 흐름을 시스템이 스스로 감지하고, 사람 개입 없이 전략 파라미터를 재조정한다.

⇄Cascade LLM 라우팅

Gemini Flash로 우선 처리하고, 판단이 어려운 경우에만 Claude Sonnet으로 승격한다.

▣실시간 대시보드

Glassmorphism UI로 5개 에이전트의 상태를 한 화면에서 확인한다.

◆운영 데이터 자동 축적

모든 판단과 재튜닝 이력이 .self_healing 폴더에 쌓여 다음 판단의 근거가 된다.
