프로젝트 폴더를 넘기면
카드뉴스가 되어 나온다

개발자가 만든 프로젝트를 인스타그램·스레드·X에 알리는 일은 반복 작업이다. PromoPilot은 로컬 프로젝트 폴더를 분석해 플랫폼별 카드뉴스를 만들고, 렌더링 결과를 AI가 직접 눈으로 검수해 배치를 고친 뒤 게시까지 이어간다.

렌더한 카드를 AI가 다시 눈으로 보고, 어긋난 배치를 스스로 고쳐 재렌더한다 — 이 순환이 PromoPilot의 핵심이다.

Core

핵심 기능

01

프로젝트 폴더 자동 분석

로컬 프로젝트 폴더를 읽어 홍보에 쓸 정보를 스스로 파악한다.

02

플랫폼별 맞춤 카드 생성

인스타그램·스레드·X 각각의 형식에 맞춰 카드뉴스를 따로 만든다.

03

AI 시각 검수

Playwright로 렌더한 PNG를 AI가 다시 검토해 배치를 자동으로 보정한다.

04

게시 3모드

dry-run · live · 수동 세 가지 모드로 게시 방식을 고를 수 있다.

05

캠페인 히스토리 영속화

실행한 캠페인 기록을 남겨 이후에도 확인할 수 있다.

06

원클릭 설치·실행

start.command 하나로 설치와 실행을 끝낸다.

07

SSE 스트리밍

생성 진행 상황을 서버-센트 이벤트로 실시간 전달한다.

08

휴리스틱 폴백 모드

모델 호출이 어려울 때는 휴리스틱 규칙으로 대체 동작한다.

Publish

게시 모드 선택

DRY-RUN

실제 게시 없이 결과만 확인

카드뉴스와 캡션을 생성·검수까지 진행하되 API 게시는 실행하지 않는다. 결과를 먼저 눈으로 확인할 때 쓴다.

LIVE

검수를 마친 카드를 바로 게시

X·Threads·Instagram API를 호출해 검수까지 끝난 카드뉴스를 곧바로 게시한다.

수동

생성 결과를 사람이 검토한 뒤 게시

자동 생성·검수까지는 동일하게 진행하고, 게시 여부는 직접 결정한다.
